## 🔬 Design Audit — Apa yang saya lihat

**Style identified:** Dark Mode Native (~85%) dengan sentuhan Developer / Neubrutalism (~15%)
> Bukti: Penggunaan background gelap solid dipadukan dengan warna aksen neon (orange) kontras tinggi, elemen antarmuka yang mengotak (mockup browser), serta tipografi heading yang sangat tebal/blocky[cite: 1, 2].

**Mood:** Energetic, technical, bold, edgy
**Comparable to:** Developer tools, e-sports branding, Vercel/Next.js dark mode aesthetics[cite: 1]

### 🎨 Color Palette
- Primary: #F59E0B (Vibrant amber/orange — digunakan untuk primary CTA, garis timeline, dan banner marquee)[cite: 1, 2]
- Background: #121212 (Deep charcoal / near-black canvas)[cite: 1, 2]
- Surface: #1E1E1E (Slightly lighter dark grey untuk card pengalaman & projek)[cite: 1, 2]
- Text-primary: #F9FAFB (Off-white, contrast ratio sangat tinggi, ✅ WCAG AAA)[cite: 1, 2]
- Text-secondary: #9CA3AF (Muted cool gray untuk paragraf deskripsi)[cite: 1, 2]
- Border: #333333 (Untuk hairline border pembatas antarmuka)[cite: 1, 2]

### 🔤 Typography
- Heading: Custom Display/Block font bergaya retro atau heavy-pixelated, weight 900 (Black)[cite: 1, 2]. Menjadi focal point utama dari desain ini.
- Body: Geometric sans-serif (kemungkinan Inter atau Roboto), ukuran ~14-16px, weight 400, line-height normal (~1.5)[cite: 1, 2].
- Marquee text: Uppercase, tracking (letter-spacing) tebal dan rapat[cite: 2].

### 📐 Layout
- Grid: 12-column grid terpusat (centered)[cite: 1, 2].
- Max-width: ~1024px hingga 1200px[cite: 1, 2].
- Whitespace: Sangat generous di margin antar-section vertikal, memberikan breathing room yang luas[cite: 1, 2].
- Hierarchy strategy: Mengandalkan dominasi size dan weight contrast pada typography heading untuk mengarahkan mata user[cite: 1, 2].

### 📏 Spacing
- Base: 8px grid system[cite: 1, 2].
- Padding card: ~24px (lg token) pada card "Projek" dan "Pengalaman"[cite: 2].
- Gap section: ~96px hingga 128px (3xl+ token)[cite: 2].

### 🟦 Shape & Radius
- Subtle rounded (4-8px) dominan pada card "Projek" dan elemen window browser mockup di Hero section[cite: 1, 2]. 

### 🌫️ Elevation
- Flat design[cite: 1, 2]. Tidak ada drop shadow yang terlihat. Kedalaman (depth) murni dicapai dari tonal elevation (perbedaan warna surface vs background) dan 1px hairline border[cite: 1, 2].

### 🧩 Components Detected
- Hero Browser Mockup: Header bar dengan 3 mac-style dots, title bar, content area dengan text dan image placeholder[cite: 1].
- Buttons: Solid primary CTA dan outline secondary CTA[cite: 1].
- Timeline / Stepper: List item dengan garis konektor vertikal di kiri (untuk "Pengalaman" dan "Pendidikan")[cite: 1].
- Infinite Marquee: 2 baris running text berlawanan arah (gelap & primary) untuk list tech stack[cite: 1].
- Card Grid: 2-kolom grid pada bagian "Projek" berisi image, judul, deskripsi, dan link pills[cite: 1].
- Footer Contact Banner: Full-width banner orange dengan background text raksasa dan floating contact cards[cite: 1].

### 🖼️ Iconography & Imagery
- Iconography: Minimalis, filled icons kecil (16-20px) pada tombol kontak dan card projek[cite: 1, 2].
- Imagery: Menggunakan placeholder kotak abu-abu (280x320 & 240x320) dengan aspect ratio portrait[cite: 1].

### 🎯 Screen Type
- Personal Developer Portfolio / Landing Page (Single-page)[cite: 1].
